基本操作

  1. popupへ高校数学の問題を入力します。
  2. 答え・ヒント・途中式・解説からモードを選びます。
  3. 「解析する」を押し、検証ラベルを確認します。
  4. どの段階で解けたか自己評価します。

Webページの選択とショートカット

ページ上の問題文を選択し、popupの「選択中の文章を取得」または Ctrl+Shift+Y を使います。選択がない場合、クリップボードは読み取らずエラーを表示します。Chrome内部ページや一部PDFでは利用できません。

5つの出力モード

答えは最終結果、ヒント1は着眼点、ヒント2は公式や次の変形、途中式は解答過程、解説は分類・考え方・検算までを示します。検証済みソルバーの答えはAIより優先されます。

学習ログ・自己評価・分析

自力100点、ヒント1は80点、ヒント2は60点、途中式40点、解説理解30点、答え閲覧・未解決は0点です。60点以下、未評価、答えモード、未検証AI回答などは復習対象になります。

図形エディタ

テンプレートを選び、辺や角の値を入力します。点のドラッグは表示だけを変え、数学条件には影響しません。初期版で実計算するのは主に三角形です。UIのみの条件には「未対応」と表示されます。

Ollamaの導入（Windows）

Ollama公式ダウンロード / Windows版

  1. OllamaSetup.exeをダウンロードしてインストール
  2. PowerShellで ollama --version
  3. ollama pull qwen3:8b
  4. ollama run qwen3:8b
  5. 別画面で ollama ps を確認

Chromeへ読み込む

  1. chrome://extensions を開きます。
  2. デベロッパーモードをONにします。
  3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます。
  4. 必要なら拡張をツールバーへ固定します。

エラー対処と制限

  • 接続エラー: Ollama起動、モデル、URLを確認。
  • 選択取得エラー: 通常のHTTP/HTTPSページで再試行。
  • 未検証: ソルバー未対応でAIのみが生成した回答。必ず自分でも確認。
  • デモ: 固定例だけで動き、一般問題への代替回答はしません。
