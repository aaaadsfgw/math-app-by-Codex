# Product specification

## Objective

Provide a local-first Chrome extension that obtains a high-school mathematics question, classifies it, attempts a verifiable local solution, uses Ollama only when appropriate, labels the evidence honestly, and records the learner’s level of independence.

## Functional flow

1. Obtain typed or explicitly selected text.
2. Normalize and classify the question with a rule-based classifier.
3. Attempt an appropriate local solver.
4. Verify the candidate result against the given equation or conditions.
5. Prefer a verified answer over model output.
6. For unsupported questions, optionally request Ollama and label the result unverified.
7. Parse output by mode, copy on request, and persist a normalized learning record.
8. Calculate review eligibility and aggregate learning metrics from real history.

## Evidence states

- `solver`: computed and checked locally; `verified` is true.
- `demo`: fixed demonstration data; `verified` is false.
- `ai-only`: generated by local Ollama without mathematical verification; `verified` is false.
- `unsupported`: no usable supported solver or allowed AI result.

## Data and privacy

Production persistence uses `chrome.storage.local`. Network traffic is limited by manifest host permissions to the local Ollama port. No clipboard read, cloud API, API key, CDN, or external server is used.

## Current boundary

The implemented local coverage is intentionally narrower than the classifier. Classification can route exponentials, calculus, probability, and other topics, but those topics remain AI-only and unverified unless a future solver is added.
