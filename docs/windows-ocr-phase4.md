# Windows OCR Phase 4 検証

## 範囲選択から解答のコピーまで

トレイ常駐中でも、`Ctrl+Shift+X` で印刷された問題を1問囲むと、OCRと入力検証が
始まる。分割と認識の重大な警告がなく、問題番号・日本語の指示・数式が整合する場合、
構造化した問題を既存の `solveWorkflow` に渡す。数学エンジンが検証した解答だけを
Windowsクリップボードに書く。処理が成功してもウィンドウを前面に出さず、通知から
結果を開ける。計算に渡した問題文、元画像、LaTeX、解答、定義域や条件を画面に残す。

画像と読み取りを照合する案内や、配置と文字認識の両方で識別できた問題番号の案内は、
自動計算を妨げない。同一行の括弧付き番号と係数の曖昧さ、候補の競合、未対応の
LaTeX、画像から分数を検出したのに出力に分数がない場合、指示や数式の入力検証が
失敗した場合は確認画面に進む。構文が成立しても、OCRが画像を正しく転写した保証はない。
入力欄を修正して「再計算」を選ぶと、その問題を直接計算する。「再認識」は同じ元画像を使う。
計算不能・計算タイムアウトとOCR失敗は区別して表示する。

## クリップボードの保護

範囲選択を表示する前に Windows のクリップボード変更番号と所有ウィンドウを記録する。
コピー直前に Windows API でクリップボードをロックし、記録と一致する場合に限って
検証済みの解答を書き込む。テキストが同じ値に戻った場合や、書式だけが変更された
場合も変更番号を比較する。確認できない場合や変更があった場合、解答はアプリ内から
取得できる。自動計算の経路がクリップボードから取得するのは変更番号と所有情報のみ。
キャンセル時は OCR または計算ワーカーを停止し、書き込みに進まない。最後の
クリップボード書き込みが始まると、終了まで1回の確定処理として扱う。
[Windowsのクリップボード変更番号](https://learn.microsoft.com/ja-jp/windows/win32/api/winuser/nf-winuser-getclipboardsequencenumber)

## Windows 実機

Windows x64、125%表示、Electron 45.2.3、Pix2Text MFR 1.5 CPU で実施した。
既存のデスクトップアイコンで起動したアプリを最小化し、別ウィンドウの
`2x^2−7x+3=0` を `Ctrl+Shift+X` で選択した。追加操作なしで実クリップボードに
`x=1/2,3` が入り、別プロセスの入力欄に貼り付けられた。完了時もアプリは最小化されていた。
デスクトップアイコンから開き直し、元画像、認識した式、計算に渡した式、解答、コピー完了表示を確認した。

独立した実画面テストでは、トレイを作成したアプリで7回の取り込みを実行した。
既定キーが使用中だったため取り込みに `Ctrl+Shift+W`、従来のクリップボード計算に
`Ctrl+Shift+Q` を割り当てた。各回とも自動書き込みは検証済み解答の1回で、
別プロセスの WinForms 入力欄へ貼り付けた。従来の計算ショートカットでも
`2+3` が `5` になった。元のクリップボードは HTML などの形式ごとメモリに退避し、
テスト終了後に復元した。

| 実画面の問題 | 自動コピーされた解答 |
| --- | --- |
| 四則演算 `2+3`（初回・ウォーム） | `5` |
| 二次方程式 `2x^2−7x+3=0` | `x=1/2,3` |
| 日本語指示付き展開 `(x+2)(x−3)` | `x^2-x-6` |
| 番号付き分数 `(x^2−5x+6)/(x−2)` | `x-3（ただし x≠2）` |
| 積分 `∫ 2x cos(x^2) dx` | `sin(x^2)+C` |
| 極限 `lim_(x->1) (x^2−1)/(x−1)` | `2` |

## 選択確定からコピーまで

| 工程 | 初回の算術 | ウォーム6回の中央値 |
| --- | ---: | ---: |
| 画像取得 | 479 ms | 374 ms |
| OCR（数式変換を含む） | 2,199 ms | 879 ms |
| LaTeX変換 | 0.69 ms | 0.17 ms |
| 数学エンジン | 171 ms | 101 ms |
| 書き込み直前の確認とクリップボードコピー | 384 ms | 352 ms |
| 選択確定からコピー完了まで | 3,237 ms | 1,708 ms |

ウォーム時の総時間は1,415〜2,080 ms。初回のOCRにはモデル読み込み約1,195 msを
含む。数式の長さや画面環境によって処理時間は変わる。
[実クリップボードを使った実測データ](../bench/ocr/windows-phase4-live.json)

今回の実画面検証は Pix2Text を使用した。IBEM への切り替えは引き続き可能で、
IBEM を選んだ状態での自動計算時間は計測していない。

再現するには Pix2Text をセットアップした Windows で以下を実行する。
元のクリップボードを保護できない場合、スクリプトは書き込みを開始せず終了する。

```powershell
npm.cmd exec --no -- electron scripts/windows-phase4-ocr-smoke.mjs phase4-live.json
```
