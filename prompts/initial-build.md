# Initial build request summary

Create a new, independent build-free Chrome extension named Math Study Log AI. It must combine solver-verified mathematics with stateless local Ollama assistance; offer answer, two hint levels, steps, and explanation; capture typed or selected questions; copy via a Chrome command; store assessment-driven learning history; expose history, analytics, review, settings, examples, help, and about pages; and provide an SVG geometry editor whose display coordinates are separate from explicit mathematical constraints.

The build must avoid cloud AI, API keys, external servers, CDNs, clipboard read access, unsafe dynamic evaluation, deceptive verification labels, placeholder controls, and undocumented unfinished behavior. It must include automated tests, static validation, complete documentation, and an initial Git commit.
