# Revised implementation brief

Build Math Study Log as a build-free Manifest V3 Chrome extension with a
deterministic offline mathematics engine and a local learning log.

Support answer, two hint levels, working, and explanation from one verified
solution trace. Preserve typed and selected input, the keyboard shortcut,
clipboard write, history, assessment, analytics, review, settings, examples,
help, and about pages.

Use no AI, external server, network host permission, API key, remote script,
dynamic code execution, image recognition, diagram editor, diagram-dependent
geometry solver, or proof generator. Expand tested textual/formula coverage from
junior-high mathematics through Japanese Mathematics III in the milestone order
defined by `PLAN.md`.
